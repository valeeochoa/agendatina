event_repeat Turnos y Descansos

Modalidad de Turnos

Configura cómo y cada cuánto tiempo pueden reservar tus clientes.

⚡ Según la Duración del Servicio (Recomendado): Los turnos de tu agenda se calculan dinámicamente según el tiempo que dura cada servicio (Ej: 1h 30m para uñas, 2hs para pestañas). Si un cliente reserva a las 9am de uñas (9:00 - 10:30), los siguientes turnos disponibles para ese profesional se adaptarán automáticamente a partir de las 10:30 hs.
Opcional

Elige cuántos minutos libres deseas dejar entre un turno y el siguiente para descansar, higienizar el gabinete o preparar materiales.

💡 ¿Cómo funciona? Al generar los horarios en tu calendario, cada bloque sumará Duración del Servicio + Tiempo de Descanso. En el último turno de la mañana o del día, el turno podrá reservarse igualmente aunque el tiempo de descanso posterior caiga después del horario de cierre.
🔒 Requerido para Cupos y Alumnos

Si eliges "No", al reservarse un turno se bloqueará la franja horaria correspondiente para ese profesional y los nuevos turnos se generarán a partir de la finalización del servicio. (En el Módulo de Cupos y Alumnos esta opción permanece habilitada permanentemente para permitir múltiples alumnos en las clases).

¿Cambiar a Modalidad Reserva Libre?

info Importante sobre tus Alumnos y Cupos:

  • El Portal del Alumno y la reserva mediante pases/créditos quedarán suspendidos.
  • Tu página web pública volverá a mostrar el calendario tradicional de turnos individuales (1 a 1).
  • Los cupos e inscripciones grupales quedarán inactivos, y pasado un tiempo de inactividad podrían desactivarse permanentemente.
